# Tools and baselines

Free and public resources that help with the technical requirements. This repo's own scripts are first on the list.

| Resource | Helps with |
|---|---|
| [`Invoke-CpcscEndpointAudit.ps1`](../scripts/Invoke-CpcscEndpointAudit.ps1) and [`Merge-CpcscAuditReports.ps1`](../scripts/Merge-CpcscAuditReports.ps1) | Read-only Windows audit for the technical requirements, with a fleet summary and evidence files |
| [CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks) | Hardening configuration standards for operating systems, cloud platforms, and network devices; supports [`03.04.02`](../controls/04-configuration-management.md) configuration settings |
| [DISA STIGs](https://public.cyber.mil/stigs/) | Detailed configuration guidance from the US Defense Information Systems Agency; free to download |
| [Microsoft Security Compliance Toolkit](https://learn.microsoft.com/en-us/windows/security/operating-system-security/device-management/windows-security-configuration-framework/security-compliance-toolkit-10) | Microsoft's security baselines and the Policy Analyzer for comparing them with what's applied |
| [Study Windows Configuration Utility](https://hans.study/tools/workstation-config/) | Windows hardening from hans.study |
| [NVD](https://nvd.nist.gov/) | The US National Vulnerability Database, for [`03.11.02`](../controls/11-risk-assessment.md) vulnerability monitoring |
| [CISA Known Exploited Vulnerabilities](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) | The vulnerabilities attackers are using now; a good order to patch in |
| [Cyber Centre alerts and advisories](https://www.cyber.gc.ca/en/alerts-advisories) | The Canadian feed for [`03.14.03`](../controls/14-system-and-information-integrity.md) |
| [Policy builder](https://hans.study/tools/policy-builder/) | Policies filled with your details, for [family 15](../controls/15-planning.md) and others |
