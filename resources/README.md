## Add a resource

Three ways, in order of effort:

- Email [contact@hans.study](mailto:contact@hans.study) with the link and a line on why it's useful.
- Open an issue with the [suggest a resource](https://github.com/hansstudy/CPCSC/issues/new?template=suggest-a-resource.yml) form.
- Send a pull request that adds a row to the right page. Fork the repo, edit the table, and open the request; GitHub's [pull request guide](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request-from-a-fork) walks through it.

What gets in: primary sources, free tools, and material that's accurate, current, and useful to a small supplier working toward CPCSC. Each row has a link, a name, and one line on what it covers. Vendor marketing, gated whitepapers, and anything that can't be checked don't make the cut.
