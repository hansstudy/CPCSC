# Glossary

| Term | Meaning |
|---|---|
| CPCSC | Canadian Program for Cyber Security Certification, run by Public Services and Procurement Canada (PSPC). |
| Specified Information | Sensitive but unclassified government information that a contract identifies as needing safeguarding on supplier systems. Canada's counterpart to Controlled Unclassified Information. |
| ITSP.10.171 | The Cyber Centre's Canadian version of NIST SP 800-171 Revision 3, with 98 requirements in 17 families. |
| Organization-defined parameter | A value the standard leaves to you, such as the inactivity period before an account is disabled. You set it, record it in your system security plan, and defend it at assessment. |
| System security plan (SSP) | The document describing your boundary, your environment, and how each requirement is met. |
| POA&M | Plan of action and milestones. A list of known gaps with owners and dates. CPCSC's rules for open items at Level 2 haven't been published. |
| Enclave | A bounded set of systems where Specified Information lives, kept separate so the assessment covers less. |
| CanadaBuys | The federal procurement portal. Level 1 results and expiry dates are confirmed in the supplier profile there. |
| Certification body | An organization accredited by the Standards Council of Canada to perform Level 2 assessments. |
| Level 1 attestation | The signed annual representation that your self-assessment is accurate, made in a federal contract context. |
| DAW | Dedicated administration workstation, the subject of `03.14.09`, the one requirement Canada added to the NIST set. |
| CMMC | Cybersecurity Maturity Model Certification, the US Department of Defense program built on NIST SP 800-171. |
| FCI and CUI | Federal Contract Information and Controlled Unclassified Information, the US data classes. CUI is the counterpart of Specified Information. |
| C3PAO | CMMC Third-Party Assessment Organization, accredited under the Cyber AB structure. |
| SPRS | Supplier Performance Risk System, where CMMC results are filed. |
| Not allocated | An identifier NIST withdrew in Revision 3, kept in the Canadian numbering so the numbers line up across the border. |
